# Security foundation status — Project Eclipse

The earlier report on `main` claimed 49 passing security tests and complete auth, tenant isolation, audit, and rate-limit modules. The referenced tests and most modules were absent from the tracked tree. That 49-test result is **unverified for the published commit** and must not be used as release evidence.

This branch restores a process-local development foundation: registration creates an analyst in a new opaque tenant, login checks a bcrypt hash, and protected API groups verify a signed JWT against current server-side user state. Role and tenant claims alone do not grant access. Registration rejects client-supplied role/tenant fields. A per-tenant application audit hash chain records registration with opaque IDs. Login and registration have per-process IP limits. Unimplemented writes and exports explicitly return 501 instead of success-shaped responses.

This is **not ready for production or a pilot**. Production lifespan startup explicitly refuses the in-memory store. Users, tenant records, audit events, and rate limits are in memory, disappear on restart, and are not shared across workers. There is no tenant-member invitation/admin provisioning flow, durable database authorization, immutable audit storage, key rotation, or complete alert/case workflow. The alert/entity/case read endpoints still return scaffold data. The audit hash chain detects changed entries during verification, but cannot establish that the last entry was not deleted without an independently anchored head. Local tests demonstrate only these bounded code paths, not the prior report's ten claimed invariants. The health endpoint and development registration/login remain public by design.

Before production use, implement durable tenant-scoped persistence, transactions, shared limits, audit storage with independent integrity controls, secure provisioning and recovery, and complete endpoint-specific authorization. Repeat security tests against the actual data layer, including IDOR and injection cases.
